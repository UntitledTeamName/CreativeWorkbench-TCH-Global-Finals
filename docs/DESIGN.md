# Story Universe Architect — Design System & Visual Identity

## Core Visual Philosophy
- **Restrained Editorial Aesthetics**: Dark mode slate theme (`#0f1218` background, `#1b2230` cards, `#7c6cff` primary accent, `#36c2b4` secondary teal).
- **Typography**: System font stack (`system-ui, -apple-system, sans-serif`) with crisp contrast and readability.
- **Native SVG Atlas**: Zero third-party canvas or chart dependencies. Clean SVG nodes, tension links, and interactive drag positioning.
- **Micro-Animations**: Smooth transitions on tab changes, modal popovers, and inspector trays.
- **Offline & Self-Contained**: No CDNs, no external font requests, zero tracking pixels.
