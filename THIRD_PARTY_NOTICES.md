# Third-Party Notices & Provenance

## Provenance & Attribution
Story Universe Architect adapts narrative relationship modeling and communication lens concepts from the research repository [THRESHOLD](https://github.com/ahmad-ovh/THRESHOLD/tree/0834fc71f9b809c856abc96b3d15434cf53a76d1) (pinned commit `0834fc71f9b809c856abc96b3d15434cf53a76d1`):
1. **Communication Lenses**: The 16 narrative lenses (`architect`, `catalyst`, `mediator`, etc.) are adapted from source character profiles to describe behavioral communication tendencies in writing, not clinical psychological diagnoses.
2. **Asymmetric Relationship Memory**: Narrative tension is modeled via two contrasting interpretations of a shared formative event.
3. **No Game Engine Bundling**: SUA is an authoring tool for novelists and screenwriters; no Godot engine, compiled game binaries, or audio assets are embedded.
4. **Native Web Stack**: The web interface uses native browser HTML5, CSS3, ES2022 JavaScript, and inline SVG. Zero third-party web frameworks, CDNs, or font packages are loaded at runtime.
